# OsmAnd Skill

## Adding a Location Marker
1. Open OsmAnd → tap Search (magnifying glass)
2. Type the location name (e.g., "Planken, Liechtenstein")
3. If an exact match appears, tap it. If only **"SHOW ON MAP"** or a generic result appears, tap "SHOW ON MAP" — it geocodes correctly.
4. After the map centers on the location, **tap the map pin/point** to open the context sheet at the bottom.
5. In the context sheet, scroll action buttons horizontally and tap **"Marker"** (flag icon). Do NOT tap "Share" or "Direction".
6. Verify a flag icon appears on the map.

## Common Mistakes
- Do NOT pick a country-level result (e.g., "Liechtenstein") when searching for a village — the marker will be at the country centroid, far from the target.
- Do NOT long-press the map — coordinates may be wrong.
- If you can't find the Marker button, scroll the action buttons horizontally.

## Searching for Locations
- Use the search bar, not manual map navigation.
- For small villages, "SHOW ON MAP" is often the best result — it geocodes the search text directly.
- If search returns nothing useful, try coordinates (e.g., "47.18, 9.54").

## Navigating Routes
When asked to create a route or navigate between locations:
1. Use Directions (arrow icon) to set start and destination.
2. If a location doesn't appear in search, try coordinates.
3. Tap "Start" or "Go" to begin navigation/route planning.
