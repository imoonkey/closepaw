# OsmAnd Skill

## Adding a Location Marker
To add a marker for a named location:
1. Open OsmAnd
2. Tap the Search button (magnifying glass icon)
3. Type the location name (e.g., "Ruggell, Liechtenstein")
4. Select the correct search result from the list
5. The map will center on that location with a context menu at the bottom
6. In the bottom context menu, look for and tap **"Marker"** or **"Add marker"** button
7. **CRITICAL**: Do NOT tap "Share" or "Direction" — these are nearby buttons that look similar. The marker button typically shows a flag/pin icon.
8. Verify the marker was added (a flag icon should appear on the map)

## Common Mistakes to Avoid
- **Do NOT long-press the map** to add a marker — this may place it at the wrong coordinates
- **Do NOT tap "Share"** thinking it's the marker button — Share is for sharing the location, not marking it
- If the bottom context sheet shows "Actions", look for "Mark" or "Marker" specifically
- If you can't find the Marker button, scroll the action buttons horizontally — it may be off-screen

## Searching for Locations
- Use the search bar, not manual map navigation
- For Liechtenstein locations, type the full name (e.g., "Planken, Liechtenstein")
- Wait for search results to load before tapping
