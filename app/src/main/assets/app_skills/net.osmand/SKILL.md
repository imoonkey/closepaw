# OsmAnd Skill

## Searching for Locations (CRITICAL)
The default search is proximity-based and often fails for villages/towns.
1. **Switch to the "Address" tab** in search — it does structured offline lookup across ALL map data.
2. If Address tab fails, use "COORDINATES SEARCH" and enter coordinates directly.
**NEVER use "SHOW ON MAP" from the general search tab** — it often geocodes to the wrong location.

## Adding a Location Marker
1. Search → **Address tab** → type location name → tap correct result
2. Tap the **map pin** to open context sheet
3. Scroll action buttons horizontally → tap **"Marker"** (flag icon)
Verify the context sheet shows the correct location name.

## Saving GPX Tracks
1. Hamburger menu (☰) → **"Plan a route"** (NOT "Directions" or "Navigation")
2. For each waypoint: search within Plan a route → **Address tab** → select locality
3. After all waypoints added, tap **Save**
"Directions/Navigation" does NOT save GPX files.
