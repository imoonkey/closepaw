# OpenTracks Skill

## Activity Type vs Track Name
Track names are user-chosen and do NOT indicate activity type. Activity types must match EXACTLY — "biking" is NOT "mountain biking". The authoritative type is only in the Edit screen.

## Reading Activity Type
Tap track → More options (3 dots) → Edit → read Activity type field → back twice to return.

## Counting/Summing by Activity Type
For any count or sum by activity type:
1. FIRST scroll the entire track list end-to-end. There are ALWAYS items below the fold.
2. Write all tracks in the date range to scratchpad as a checklist.
3. Open Edit for EVERY track on the checklist. Mark each checked.
4. For max/min queries (longest, shortest), you MUST check ALL tracks before answering.
5. Do NOT call complete_task until every track is marked checked.

## Reading Distance/Duration
Click a track to see its Stats tab — shows distance, moving time. No need for Edit.

## Date Labels
Track list uses relative labels (Today, Yesterday, Monday, etc.). Map each to an absolute date using the device date before filtering.

## Scrolling
The track list extends below the visible area. Scroll down repeatedly until content stops changing.
