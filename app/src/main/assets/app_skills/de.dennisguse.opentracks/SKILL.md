# OpenTracks Skill

## Track List View
- The track list shows track name, date, duration, and distance for each track.
- Track names in OpenTracks typically describe the activity (e.g., "Mountain Biking", "Trail Ride", "Indoor Climbing"). These names ARE the activity descriptors — you can identify activity type from them without entering Edit mode.
- For information queries: scroll through the entire track list first, note all tracks that match the criteria (date range + activity type), then compute the answer.

## Reading Track Details
- Click a track to see its Stats tab (distance, moving time, etc.) — this is the fastest way to get distance/duration data.
- Do NOT use More options → Edit to check activity type. The track name in the list view already indicates the activity type.

## Efficient Strategy for Counting/Aggregating
1. Scroll through the full track list, using scratchpad to record matching tracks (name, date, distance, duration).
2. Compute the answer from scratchpad evidence.
3. This avoids the expensive 4-turn-per-track Edit flow.
