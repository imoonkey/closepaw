# OpenTracks Skill

## Activity Type vs Track Name
Track names are user-chosen and do NOT reliably indicate activity type. The authoritative type is only visible in the Edit screen.

## Reading Activity Type
Tap track → More options (3 dots) → Edit → read Activity type field → back twice to return.

## Smart Filtering
When filtering by activity type, prioritize tracks with ambiguous names. Skip tracks whose names clearly indicate an unrelated activity. Always verify via Edit when in doubt.

## Reading Distance/Duration
Click a track to see its Stats tab — shows distance, moving time, etc. No need to enter Edit.

## Date Labels
Track list uses relative day labels (Today, Yesterday, Monday, etc.). Map each to an absolute date using the device date before filtering by date range. "Yesterday" = device_date − 1.

## Scrolling
Scroll down repeatedly until the list stops changing to see all tracks.
