# Documents UI Skill

## Navigation
If the hamburger/drawer menu doesn't open via click, swipe right from the left edge.

## File Operations
- After move/copy/delete, verify the file is at the destination and gone from the source.
- Use the search icon to locate files by exact name when the list is long.
