- If the hamburger menu doesn't open via click, swipe right from the left edge.
- After move/copy/delete, verify the file is at the destination and gone from the source.

## Safety

**DANGEROUS -- ask user before:**
- Deleting documents or folders
- Moving documents to a different location (unless task explicitly requests it)

**SAFE -- proceed normally:**
- Browsing and opening documents
- Copying files to a new location
- Navigating directories
