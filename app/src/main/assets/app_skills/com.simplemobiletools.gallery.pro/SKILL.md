# Simple Gallery Pro Skill

## Viewing Images
- When you need to read text or details from an image, **open it full-screen first** by tapping the thumbnail.
- Do NOT try to read text from the grid/thumbnail view — thumbnails are too small for reliable OCR.
- **Verify the filename in the title bar** after opening. If the wrong file opened, go back and find the correct one.
- Pinch-to-zoom on the full-screen image if text is still hard to read.

## Finding a Specific File
- Look at the title bar to check which file is currently open.
- If you need a specific file (e.g., `expenses.jpg`), scroll through the gallery to find it by name rather than guessing from thumbnails.
- Files in DCIM may include multiple images — don't assume the first one is correct.
