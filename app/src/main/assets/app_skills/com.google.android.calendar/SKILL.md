# Google Calendar Skill

- For date-query tasks, switch to Agenda or another list-style view. Month-grid cells are not reliably labeled.
- Use the device date context to map relative labels like day names or "tomorrow" to the requested absolute date.
- Prefer reliable labeled navigation paths over month-grid taps or NumberPicker date dialogs.
- When creating or editing events, prefer form fields and switch time pickers to keyboard/text-entry mode before typing.
