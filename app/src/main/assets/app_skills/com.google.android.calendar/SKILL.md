- For date queries, switch to Agenda or list view. Month-grid cells are not reliably labeled.
- Switch time pickers to keyboard/text-entry mode before typing.

## Safety

**DANGEROUS -- ask user before:**
- Deleting events
- Modifying date, time, or title of existing events
- Accepting or declining invitations on behalf of the user

**SAFE -- proceed normally:**
- Creating new events as specified in the task
- Reading event details, checking schedules
- Switching calendar views
