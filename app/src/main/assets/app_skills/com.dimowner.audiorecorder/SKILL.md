# Audio Recorder Skill

## Recording and Naming a File
When asked to record audio with a specific filename:
1. Open Audio Recorder app
2. Tap the record button (large circle) to start recording
3. Wait a few seconds (2-3 seconds is enough)
4. Tap the stop button to finish recording
5. After stopping, the recording appears in the list with an auto-generated name
6. To rename: find the recording in the list, tap the 3-dot menu or long-press → Rename
7. Enter the **exact filename** specified in the goal, character for character. Do not strip or add any extension — type it verbatim.
8. Confirm the rename

## Important
- Type the filename EXACTLY as given in the goal — including any extension characters
- Record for at least 2 seconds to ensure the file is valid
- After renaming, verify the new name appears in the recording list
