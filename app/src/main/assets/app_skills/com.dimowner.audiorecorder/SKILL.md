# Audio Recorder Skill

## Recording and Naming a File
1. Tap record button (large circle) → wait 2-3 seconds → tap stop
2. Recording appears in list with auto-generated name
3. To rename: tap 3-dot menu or long-press → Rename
4. Type the **exact filename** from the goal verbatim, including any extension characters
5. Confirm rename and verify the new name in the list
