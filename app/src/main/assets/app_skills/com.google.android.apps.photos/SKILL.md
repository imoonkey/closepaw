# Gallery Skill

## Viewing Images
- When you need to read text or details from an image, **open it full-screen first** by tapping the thumbnail.
- Do NOT try to read text from the grid/thumbnail view — thumbnails are too small for reliable OCR.
- Pinch-to-zoom on the full-screen image if text is still hard to read.

## Navigating
- Use the bottom navigation or back button to return to the gallery grid.
- Images are sorted by date. Scroll to find older images.
