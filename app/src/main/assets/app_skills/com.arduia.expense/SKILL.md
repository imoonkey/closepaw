# Pro Expense Skill

## Adding Expenses
- Tap FAB to add. **Fill ALL 4 fields**: name → amount → category → note → save.
- Before saving, re-read name and amount fields — field focus issues can silently overwrite the wrong field.

## Category Selection
- Category row scrolls horizontally (5 visible at a time). **Scroll left/right to reveal all categories before selecting.**
- Match category text exactly.

## Viewing All Expenses
- Home "Recent" shows only a few entries. For complete view: menu → Expense Logs. Scroll to see all.

## Comparing Expenses
- Same-name expenses may differ in amount, category, or note. Open each to compare all fields.

## Deleting Expenses
- Swipe left, or long-press → Delete, or open → Delete.
