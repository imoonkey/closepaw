# 不同屏幕/app状态与Smart Capsule关系

这个设计让主app界面的底部，跟浮窗smart capsule，始终保持一致。方便用户理解。也方便用户在不同模式之间切换。

## (1) 主 App 状态
┌──────────────────────────┐
│[⋯] Header                │
├──────────────────────────┤
│ Chat                     │
│ history                  │
│ …                        │
│                          │
│                          │
│                          │
│   ╭──────────────────╮   │
│   │   Smart Capsule  │   │
│   ╰──────────────────╯   │
└──────────────────────────┘

## (2) 观看屏幕状态（Accessibility 模式 / VD 模式 LiveView）
┌──────────────────────────┐
│          屏幕内容          │
│                          │
│        (LiveView)        │
│                          │
│                          │
│   ╭──────────────────╮   │
│   │   Smart Capsule  │   │
│   ╰──────────────────╯   │
└──────────────────────────┘

## (3) 后台模式（仅在VD存在）
A) 缩小到 Status Island（悬浮）
┌──────────────────────────┐
│ ╭──────────────╮         │
│ │    island     │         │
│ ╰──────────────╯         │
│          屏幕内容          │
│                          │
│                          │
└──────────────────────────┘

A -- 点击 island → B

B) 回到主屏幕（底部 Smart Capsule 扩展）
┌──────────────────────────┐
│          主屏幕           │
│                          │
│                          │
│   ╭──────────────────╮   │
│   │  [1]  [2]  [3]   │   │
│   │   Smart Capsule  │   │
│   ╰──────────────────╯   │
└──────────────────────────┘

[1] 缩小回 Status Island --> 到 (3)A
[2] 进入主 App 状态 --> 到 (1)
[3] 进入屏幕观看状态 --> 到 (2)

这三个button/action:
1. 在 (1) 中 
    - 如果是Accessibility模式，
      - 在等待状态，只显示 [1]，相当于退出app界面。
      - 在agent操作状态时，不显示任何button，因为agent正在操作屏幕。
      - 在agent暂停状态时 (比如等待用户输入), ...
    - 如果是VD模式显示[1][3]。不显示[2]，因为就在主app。
2. 在 (2) 中
    - 如果是Accessibility模式，agent在操作屏幕，显示[1][2]。不显示[3]，因为本身状态在观看屏幕，而且无法退出。
    - 如果是VD live view模式，agent在操作屏幕，显示[1][2][3]。
3. 在 (3)A 中
    - 显示[2][3]。
4. 在 (3)B 中
    - 显示[1][2][3]。
