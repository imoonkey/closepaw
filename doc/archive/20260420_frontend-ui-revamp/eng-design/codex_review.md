# Frontend UI Revamp Review

## Critical

1. **`SettingsRow` violates the D1 contrast matrix for missing-permission rows.** The new status label uses `MaterialTheme.colorScheme.tertiary` for `"Required"` on a `surfaceVariant` row in [SettingsWidgets.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/main/kotlin/ai/closepaw/ui/settings/SettingsWidgets.kt:225). In light theme that is Amber on PaperInset, which the matrix explicitly marks as a hard fail (`1.77:1`) in [contrast-matrix.md](/Users/moonkey/workspace/android-agent-workspace/androidagent/doc/todo/frontend-ui-review/aligned/contrast-matrix.md:62). This surfaces immediately from [PermissionsAdvancedSettingsPage.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/main/kotlin/ai/closepaw/ui/settings/PermissionsAdvancedSettingsPage.kt:76). Amber needs to stay a fill/icon treatment here; the text needs an AA-safe foreground.

2. **Complete rows never enter the default-collapsed Track A state.** `AgentRow` remembers `collapsed` only by `message.id`, so rows that start as `Live` initialize `collapsed = false` and stay expanded when `rowState` later becomes `Complete` in [MessageBubble.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/main/kotlin/ai/closepaw/ui/chat/components/MessageBubble.kt:117). That breaks both the Track A spec (`Complete` is collapsed by default) in [track-a design_aligned.md](/Users/moonkey/workspace/android-agent-workspace/androidagent/doc/todo/frontend-ui-review/eng-design/track-a/final/design_aligned.md:127) and the chat state machine in [ui_chat.md](/Users/moonkey/workspace/android-agent-workspace/androidagent/doc/main/state_machines/ui_chat.md:156). The new tests only assert reducer enum transitions in [ChatThoughtAndRowStateTest.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/test/kotlin/ai/closepaw/ui/chat/ChatThoughtAndRowStateTest.kt:116), so this UI-state regression is currently unguarded.

## Important

1. **The collapsed row summary is knowingly incomplete versus Track A.** The implementation explicitly skips headline step 1 (“use the user message”) in [MessageBubble.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/main/kotlin/ai/closepaw/ui/chat/components/MessageBubble.kt:358), and the collapsed/complete footer path renders only a timestamp in [MessageBubble.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/main/kotlin/ai/closepaw/ui/chat/components/MessageBubble.kt:153) instead of the required single-line `headline · N actions · elapsed` summary in [track-a design_aligned.md](/Users/moonkey/workspace/android-agent-workspace/androidagent/doc/todo/frontend-ui-review/eng-design/track-a/final/design_aligned.md:153). Even after fixing the default-collapse bug, the complete-row presentation is still not the specified one.

2. **The chat renderer still keeps the old interleaved `Text + Action + Text` model alive instead of `Trace* + optional Final`.** `ExpandedTrace` renders every `ContentBlock.Text` inline in event order in [MessageBubble.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/main/kotlin/ai/closepaw/ui/chat/components/MessageBubble.kt:193), while the reducer tests now lock in “new text block after action/thought” behavior in [ChatSupplementAndActionTransitionTest.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/test/kotlin/ai/closepaw/ui/chat/ChatSupplementAndActionTransitionTest.kt:193) and [ChatThoughtAndRowStateTest.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/test/kotlin/ai/closepaw/ui/chat/ChatThoughtAndRowStateTest.kt:91). That means the implementation still surfaces multiple prose blocks inside the trace instead of the Track A/D1 `Trace* + optional Final` model in [design_aligned.md](/Users/moonkey/workspace/android-agent-workspace/androidagent/doc/todo/frontend-ui-review/aligned/design_aligned.md:190). This is a structural mismatch, not just styling drift.

3. **The D2-1 font rollout did not actually land.** `Type.kt` still aliases `Geist`, `Fraunces`, and `JetBrainsMono` to system font families behind a “swap when assets ship” comment in [Type.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/main/kotlin/ai/closepaw/ui/theme/Type.kt:10), and there is still no `app/src/main/res/font/` directory in the tree. That misses the D2 requirement that bundled font assets are a Phase 1 prerequisite in [track-d2 design_aligned.md](/Users/moonkey/workspace/android-agent-workspace/androidagent/doc/todo/frontend-ui-review/eng-design/track-d2/final/design_aligned.md:119) and means the shipped UI is not actually using the visual baseline’s typography.

4. **The D2 theme API is still only partially applied in the touched rollout files.** The design says standard shapes should come from `MaterialTheme.shapes` and the extra surface should stay thin in [track-d2 design_aligned.md](/Users/moonkey/workspace/android-agent-workspace/androidagent/doc/todo/frontend-ui-review/eng-design/track-d2/final/design_aligned.md:30), but touched drawer/settings files still instantiate local radii instead of the shared shape scale, e.g. [NavigationDrawer.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/main/kotlin/ai/closepaw/ui/navigation/NavigationDrawer.kt:197), [SettingsWidgets.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/main/kotlin/ai/closepaw/ui/settings/SettingsWidgets.kt:77), and [SettingsWidgets.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/main/kotlin/ai/closepaw/ui/settings/SettingsWidgets.kt:198). The onboarding shell also still mixes token spacing with hardcoded page padding in [OnboardingShell.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/main/kotlin/ai/closepaw/ui/onboarding/OnboardingShell.kt:44). Nothing is broken immediately, but this is a missed migration spot against the D2 API contract.

5. **The capsule cleanup stopped halfway and reintroduces presentation details below the renderer boundary.** The color/alpha cleanup happened, but `CapsuleRenderSpec` still carries dead visual icon strings and emoji-laden copy in [CapsuleRenderSpec.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/main/kotlin/ai/closepaw/ui/overlay/model/CapsuleRenderSpec.kt:28), which is at odds with both the D2 semantic-boundary rule in [track-d2 design_aligned.md](/Users/moonkey/workspace/android-agent-workspace/androidagent/doc/todo/frontend-ui-review/eng-design/track-d2/final/design_aligned.md:330) and D1’s “emoji removal from capsule chrome” in [design_aligned.md](/Users/moonkey/workspace/android-agent-workspace/androidagent/doc/todo/frontend-ui-review/aligned/design_aligned.md:172). The same file also keeps `ButtonSpec.icon`, but the Compose layer now chooses real icons independently, so that field is dead weight.

6. **The new test set is meaningful at reducer level, but not at the new row UI boundary.** The added Track C coverage is good for reducer semantics in [ChatThoughtAndRowStateTest.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/test/kotlin/ai/closepaw/ui/chat/ChatThoughtAndRowStateTest.kt:23), and the cursor test in [ChatStreamingCursorTest.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/androidTest/kotlin/ai/closepaw/qa/ChatStreamingCursorTest.kt:22) verifies the inline cursor path. But after deleting the old `ActionCard` UI tests in this diff, there is no Compose coverage for the new collapsed/expanded row behavior, collapsed summary content, or action-status accessibility. That gap is exactly why the `Live -> Complete` default-collapse bug in [MessageBubble.kt](/Users/moonkey/workspace/android-agent-workspace/androidagent/app/src/main/kotlin/ai/closepaw/ui/chat/components/MessageBubble.kt:117) currently passes.
