II

Let me see your screen

ClosePaw works through Android's accessibility service. Without it, the paw can't reach the apps you use. Granting it keeps the agent honest — every action it takes is one you'd be able to make yourself.

⏤ MISSING — ACCESSIBILITY SERVICE
Settings → Apps → Accessibility → ClosePaw → Use service

07 Motion principles Breath, not bounce
120 ms Micro — pressed state, color tint, error shake
240 ms Transition — capsule slide-in, action visualizer paw-stamp
480 ms Mode change — Running → Done, capsule scaleOut + fade, blink-once
900 ms Breath — paw scale 1.0 ↔ 1.04, three-toe loader cycle, edge-glow drift

Two easings only — EaseInOutSine for breath, EaseOutCubic for entry. No springs. No overshoot. No ripple.
