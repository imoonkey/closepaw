## Common Problems

### P1: Priority radio button scale unknown — HIGH — 1 task

**Affected**: TasksHighPriorityTasksDueOnDate

**Root Cause**: Tasks.org detail view has 4 priority radio buttons with no a11y text labels. Agent assumed rightmost = highest, but actual order is: High (red), Medium (orange), Low (blue), None (grey). Rightmost = None. Every priority check was inverted.

**Proposed Fix**: Add priority scale documentation to Tasks skill: "4 radio buttons left-to-right: High, Medium, Low, None. Leftmost checked = High priority."

### P2: Incomplete scrolling despite guidance — MED — 2 tasks

**Affected**: SportsTrackerTotalDistanceForCategoryOverInterval, TasksHighPriorityTasksDueOnDate

**Root Cause**: Both skills now say "scroll the full list" but the agent stops after viewing the initial viewport or one scroll. It treats "visible" as "complete" without confirming end-of-list.

**Proposed Fix**: Strengthen both skills with explicit scroll-until-stuck pattern: "Keep scrolling down until scroll has no effect. Do not assume visible tracks/tasks are all that exist."

### P3: AudioRecorder rename = display name only — MED — 1 task

**Affected**: AudioRecorderRecordAudioWithFileName

**Root Cause**: Audio Recorder's rename dialog changes the internal display name but not the filesystem filename. The evaluator checks the filesystem. Agent behavior was correct from a UI perspective.

**Proposed Fix**: App skill for Audio Recorder instructing: "After recording, use shell tool to rename the file on disk: `mv <auto-generated-name>.m4a <desired-name>.m4a` in the records directory." Need to verify shell access to app's data directory first.

### P4: Wi-Fi state perception — LOW — 1 task

**Affected**: TurnOnWifiAndOpenApp

**Root Cause**: Agent saw "Internet" tile in quick settings and assumed Wi-Fi was on. Status bar showed "No internet". Agent should have tapped the toggle or verified via shell.

**Proposed Fix**: For system toggle tasks, prefer deterministic shell commands (`svc wifi enable`) over UI-based visual inspection.
